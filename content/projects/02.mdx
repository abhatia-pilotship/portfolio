A multivariate Kalman Filter implemented in C for GTXR flight-computer state estimation, paired with a complementary filter. The work included a Java matrix library and handling for both Euler and quaternion formats, with sensor-fusion algorithms validated through MATLAB and Java simulation. The site states the implementation decreased estimation errors.
