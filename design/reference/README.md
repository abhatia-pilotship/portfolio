# Design references

Put ONE DESIGN.md from https://github.com/VoltAgent/awesome-design-md here, renamed
(e.g. `linear.DESIGN.md`). It is mood input only.

Do not put it in the project root: Impeccable treats a root DESIGN.md as this project's
own design system. The real root DESIGN.md is generated at the end with `/impeccable document`.
